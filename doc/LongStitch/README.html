更新流程

协议更新不需要重新发版 App。直接修改本目录下的对应文件，提交并 push 到 main 分支，URL 内容即时更新。

更新后建议：

  1. 修改对应文档的「生效日期 / Effective Date」字段为新日期
  2. 对于实质性变更（收集新类型数据、新增第三方 SDK、订阅价格调整），必须提前 30 天通知用户
