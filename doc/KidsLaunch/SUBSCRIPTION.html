1. 概述

本应用通过 Apple 的 StoreKit 提供以下应用内购买项目：

  • 会员 月订阅：¥18 / 月，自动续期。
  • 会员 年订阅：¥38 / 年，自动续期；新订阅用户享 3 天免费试用。
  • 终身版：¥88 一次性买断（非消耗型）。

订阅组名称：儿童启蒙乐园 会员（KidsLaunch Premium）。月订阅与年订阅属于同一订阅组，同一 Apple ID 在同一时间只能选择其中一个档位。

2. 自动续期说明

订阅（月订阅、年订阅）为自动续期项目。在当前订阅周期结束前至少 24 小时，您的订阅将自动续期，并从您的 Apple ID 账户扣取下一周期费用。

3. 续期价格与订阅周期

  • 会员 月订阅：¥18 / 月，订阅周期为 1 个月。
  • 会员 年订阅：¥38 / 年，订阅周期为 1 年（新用户含 3 天免费试用，试用期内取消不收费）。
  • 终身版：¥88，一次性支付，永久解锁，不续期。

上述价格为中国区价格，其他地区以 App Store 展示的当地货币价格为准。

4. 免费试用

年订阅为首次订阅的新用户提供 3 天免费试用。免费试用将在到期时自动转为付费订阅，除非您在试用结束前至少 24 小时取消。试用期内取消不收取任何费用。每个 Apple ID 仅可享受一次试用期。

5. 如何管理或取消

您可以随时取消订阅，取消后将在当前已付费周期结束时停止续期，已付费周期内的权益不受影响。取消方式：

打开 iOS 设置 → [您的姓名] → 订阅，选择”儿童启蒙乐园”并点击”取消订阅”。

终身版为一次性购买，不存在续期，无需取消。

6. 家庭共享

月订阅、年订阅与终身版均支持家庭共享。开启后，同一”家人共享”组内的成员可共享已解锁的全部内容，无需重复购买。

7. 恢复购买

更换设备或重装应用后，可在应用内 设置 → 恢复购买，通过 Apple ID 免费恢复此前已购买的全部权益，不会重复扣费。

8. 退款

所有购买均通过 Apple 完成。Apple 不支持开发者直接退款；如您需要退款，请通过 Apple 的官方渠道（报告问题：reportaproblem.apple.com）申请，由 Apple 按相关政策处理。

9. 免费内容与付费内容

每个学科的第 1 关永久免费，无需购买即可体验。订阅或买断后解锁 7 大学科的全部 37 个关卡。

10. 价格调整

Apple 会在任何价格上涨生效前至少提前通知您，并取得您的同意（如适用）。
