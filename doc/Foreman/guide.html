在 Mac 上装好 Foreman

Foreman 是手机遥控桌面 coding agent 的指挥台：Mac 端跑 Bridge，手机端发指令、看流式输出、批权限、直接操作模拟器。

01 下载与安装
  1. 点上方 下载 Foreman-1.0.0.dmg（或更新版本）。
  2. 双击打开镜像，把 Foreman 拖进「应用程序」文件夹。
  3. 从「应用程序」启动 Foreman。1.0.0 起安装包已签名并公证，正常双击即可打开。
  4. 菜单栏会出现 Foreman 图标（带 >_ 的显示器）。Foreman 是菜单栏 App，不占 Dock，关掉窗口也不会退出。
首次启动后按第 2 节授权。若系统仍提示「Apple 无法验证」，请确认下载的是 1.0.0 或更新版本；旧的 0.1.0 包未公证，不要继续使用。
02 需要授权的权限
辅助功能 按需
把手机上的轻点、滑动回灌到模拟器窗口，远程桌面操作也依赖它。只看不控制时可以不授权。
系统设置 → 隐私与安全性 → 辅助功能 → 勾选 Foreman
本地网络 可选
手机与 Mac 在同一局域网时直连，画面和指令不经云端；只走云端 Relay 时不需要。
首次启动时允许，或到 系统设置 → 隐私与安全性 → 本地网络 打开
屏幕录制 建议
远程桌面与模拟器实时画面需要。不开时模拟器会自动降级为逐帧截图，画面更卡，远程桌面不可用。
系统设置 → 隐私与安全性 → 屏幕录制 → 勾选 Foreman
只聊天、不操作模拟器或桌面时，这些权限都不是必需的。辅助功能通常几秒内生效；屏幕录制授权只在启动时读取，改完需要 退出并重新打开 Foreman（菜单栏 Foreman 图标 → 电源键）。
03 用手机配对
  1. 点菜单栏 Foreman 图标，选 主窗口。
  2. 窗口左侧会显示二维码和 8 位配对码，配对码 5 分钟内有效，可点「生成新配对码」刷新。
  3. 手机打开 Foreman，选 连接我的 Mac（已配对过则选 配对新 Mac），扫二维码或输入这 8 位数字。
  4. 手机与 Mac 在同一 Wi-Fi 时，也可以直接在手机上点这台 Mac，回到 Mac 主窗口点 允许，不用输码。
  5. 手机与 Mac 交换密钥，配对成功后指令与输出全程端到端加密，不经过账号。
配对码只在本机的 Bridge 里生成和校验。换手机或重装 App 后，在 Mac 主窗口重新生成配对码即可；已配对的 Mac 不会被移除，可随时切换。
04 开始使用
01
添加工作区
主窗口「工作区 → 添加目录」加入项目文件夹；手机新建会话时直接选，未选则落到置顶或最近使用的工作区。
02
发指令、看结果
选 Agent（WorkBuddy / Codex / Claude Code / Cursor / Trae CN / Qoder CN），输入需求即可。流式输出、思考过程和工具调用都会实时回到手机。
03
在手机上批权限
Agent 需要写文件或执行命令时，手机会进入「等你确认」；批准后操作在 Mac 上真实执行，全程可追溯。
04
预览并操作模拟器
会话页或聊天页工具栏进入预览：远程启动模拟器、看实时画面、轻点与滑动直接回灌到 Mac 上的模拟器。
05
关掉窗口也不丢会话
Bridge 在 Mac 后台运行，会话和事件落盘；关掉窗口或断开后重连可以继续。合盖休眠会暂停，唤醒后继续。
至少安装并登录一个 Agent CLI 才能开始；未安装的会在手机「设置 → 支持 Agent」里给出安装命令。模拟器实时预览、远程桌面、多台 Mac 配对、远程构建和按任务切换模型为 Pro 功能，免费版每月 20 条聊天消息。
05 常见问题
菜单栏找不到 Foreman？
Foreman 是纯菜单栏 App，图标是带 >_ 的显示器；如果图标被折叠，用 Spotlight 搜「Foreman」重新打开即可。
提示「Apple 无法验证」或「已损坏」？
请确认下载的是 1.0.0 或更新版本。1.0.0 起安装包已签名并公证，正常双击即可打开；旧的 0.1.0 包未公证，请删掉后重新下载。
Bridge 显示异常 / 一直是「等待 Bridge 启动」？
在主窗口点「重试」或「启动 Bridge」。仍失败时打开「设置」检查 Relay 地址，并确认网络允许出站 443；日志在 ~/Library/Logs/Foreman/bridge.log。
手机上提示配对失败？
配对码 5 分钟就会过期，回 Mac 主窗口生成新的再试；同时确认手机和 Mac 都能正常联网，系统时间没有偏差。
模拟器画面黑屏或很卡？
授予「屏幕录制」权限并重启 Foreman。没有该权限时会自动回退到截帧模式，帧率明显更低，但轻点回灌仍可用。
手机上轻点模拟器没反应？
检查「辅助功能」是否勾选了 Foreman。辅助功能通常几秒内生效；如果仍未生效，再退出并重新打开 Foreman。操作时确保模拟器窗口没有被其他窗口完全遮住。
怎么卸载或解绑？
点菜单栏 Foreman 图标退出，然后把「应用程序」里的 Foreman 拖进废纸篓。设备身份和会话在 ~/.foreman/，一并删除即彻底重置，手机端需要重新配对。
