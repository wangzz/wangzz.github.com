## 2. 免费试用（仅年订阅）

2.1 年订阅对**新订阅用户**提供 **3 天免费试用**。试用期内您可使用年订阅全部高级功能，且不会被扣费。

2.2 试用期结束时将**自动转为付费年订阅**并按 ¥38/年扣费，除非您在试用结束前至少 24 小时取消订阅。

2.3 已使用过年订阅免费试用的用户再次订阅时不再享受试用。

## 3. 自动续期规则（月订阅 / 年订阅）

3.1 月订阅与年订阅均为**自动续期订阅**：在每个计费周期到期前 **24 小时**内，Apple 将自动从您的 Apple ID 关联支付方式中扣款，并将订阅顺延一个周期（月订阅顺延 1 个月，年订阅顺延 1 年），直至您主动取消。

3.2 续费金额与您当初订阅时通过 App Store 实际支付的价格一致；如 Apple 调整区域定价，您将在扣款前通过 Apple 通知获知。

3.3 您可随时在 iPhone "设置 → Apple ID 姓名 → 订阅"中查看与取消订阅。**取消不影响当前已付费周期的使用**，订阅权益将持续至当前周期结束，下一周期起停止扣费并停止提供权益。

## 4. 取消与退款

### 4.1 取消订阅

- **iOS 系统设置**：打开"设置 → Apple ID → 订阅"，选择"血压记录"，点击"取消订阅"；
- **App Store 订阅页**：在 App Store 账户页的"订阅"中操作；
- **应用内入口**：本应用"设置 → 管理订阅"将调用 StoreKit 系统面板跳转至订阅管理页。

取消订阅后，您仍可在当前已付费周期内使用全部高级功能，到期后自动降级为免费版。

### 4.2 退款

所有退款均按 **Apple 的退款政策**处理。请您访问 [reportaproblem.apple.com](https://reportaproblem.apple.com) 提交退款申请，由 Apple 审核决定。开发者**不直接处理支付退款**，亦无权决定退款结果。

## 5. 恢复购买

5.1 您可在本应用"设置 → 恢复购买"中恢复历史购买记录。恢复成功后，订阅状态或买断权益将立即生效。

5.2 恢复购买要求您使用与原购买时相同的 Apple ID 登录 App Store。

5.3 买断为非消耗型购买，绑定您的 Apple ID，可在您登录同一 Apple ID 的任意设备上恢复使用，无需再次付费。

订阅或买断解锁的高级功能以应用内"升级"页与 App Store 商品描述所列内容为准，通常包括但不限于：

> 已解锁的高级功能范围可能因版本迭代而调整，您已支付费用所对应的权益不会因新增功能而被缩减。

7.1 我们可能调整订阅价格或功能范围。**价格调整将在 App Store 生效，并由 Apple 提前通知您**。已生效的自动续期订阅将按原价格继续履行至当前周期结束；下一周期起按新价格续费，您可选择取消以避免新价格扣费。
