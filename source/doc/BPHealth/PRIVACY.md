# 隐私政策

**生效日期：** 2026-08-21
**适用产品：** 血压记录（BPHealth），iOS 应用
**Bundle ID：** com.wangzz.bphealth
**联系邮箱：** wzzvictory_tjsd@163.com

> 血压记录（以下简称"本应用"）是一款帮助用户在本机记录、查看血压与心率趋势的本地化工具。我们高度重视您的隐私，本政策说明我们如何处理（或不处理）您的信息。本政策依据《中华人民共和国个人信息保护法》（PIPL）、《App违法违规收集使用个人信息行为认定方法》及 Apple App Store《隐私政策》要求编写。

---

## 1. 概述

本应用**以"本地优先、不上传、不共享"为最高隐私原则**：

- 您的血压/心率读数、家庭成员信息、可选保存的拍照缩略图，**全部仅存储于您本机的 iOS SwiftData 数据库**；
- 我们**不会**将上述任何健康数据上传到任何服务器；
- 我们**不会**与任何第三方共享您的健康数据；
- 我们**不集成任何广告 SDK 与统计分析 SDK**；
- 我们**不进行任何跨应用追踪**（NSPrivacyTracking = false）；
- 本应用**不要求注册账号**。

## 2. 我们"收集"与"不收集"的信息

### 2.1 不收集的信息

下列信息**全部仅存储于您本机，开发者从不访问、不上传、不收集**：

| 类别 | 内容 | 存储位置 |
|---|---|---|
| 健康数据 | 收缩压、舒张压、心率、测量时间、备注、来源（OCR/手动） | 本机 SwiftData |
| 家庭成员信息 | 您自填的成员姓名、关系、色标 | 本机 SwiftData |
| 拍照留存缩略图 | 可选保存的血压计屏幕缩略图 | 本机 SwiftData |
| 应用偏好 | 测量提醒、单位与显示设置等 | 本机 UserDefaults |

### 2.2 仅在您主动使用反馈功能时通过系统邮件发送的信息

当您在"设置 → 反馈建议"主动点击发邮件时，系统邮件 App 会按以下内容生成邮件草稿，**收件人为开发者邮箱 wzzvictory_tjsd@163.com**，由您审阅后手动发送：

| 字段 | 来源 | 是否含个人信息 |
|---|---|---|
| 邮件主题 | `[Feedback][BPHealth][v1.0.0][iOS17.0][<DeviceModel>]` | 否（系统公开信息） |
| 邮件正文 | App 版本、系统版本、设备型号、设备语言、Apple ID 所在地区、反馈时间 | 否（均为系统公开信息，**不含 Apple ID、姓名、健康数据**） |

上述反馈邮件的所有内容由您本人审阅与决定是否发送，**本应用不附加任何您不可见的隐藏内容**。

### 2.3 由 Apple 处理、开发者不接触的信息

- **订阅与支付信息**：所有内购交易（包括订阅状态、续费、退款）均由 Apple 通过 StoreKit 全程处理。我们仅能获取"是否已订阅 Pro 状态"的布尔结果，**不接触您的信用卡号、Apple ID 密码、具体支付金额以外的支付明细**。
- **HealthKit 数据**：详见《健康数据说明》。

## 3. 信息使用目的

### 3.1 本机健康数据

仅用于在本应用内提供以下功能：

- 历史记录列表与详情展示；
- 趋势图与达标率统计展示；
- 家庭成员分组与切换；
- 用户主动选择写入 Apple「健康」（详见第 4 节）。

### 3.2 反馈邮件

如您主动发起反馈，邮件内容仅用于回复您的问题、修复 Bug 或改进产品。

### 3.3 订阅状态

仅用于在应用内判断是否解锁高级功能与展示订阅状态，不用于其他用途。

## 4. 与 Apple「健康」（HealthKit）的交互

若您主动授权，本应用可：

- **读取**您"健康"中已有的血压、心率数据，用于在趋势页统一展示；
- **写入**您在本应用中确认的血压与心率读数到"健康"。

相关数据**仅在本机处理，不会发送到外部任何服务器**。您可随时在 iOS"设置 → 隐私与安全性 → 健康 → 血压记录"中查看或撤销授权。详见《健康数据说明》。

## 5. 数据存储与留存

### 5.1 存储方式

- 健康数据、家庭成员信息、拍照缩略图均存储于**本机 iOS SwiftData 本地数据库**；
- 应用偏好设置存储于**本机 iOS UserDefaults**；
- 本应用**不使用任何云端服务器**存储您的数据，**不使用 iCloud 同步**（V1.0 不提供跨设备同步）。

### 5.2 数据留存

- 您本机的数据将一直保留，直至您主动删除单条记录、删除整个家庭成员档案或卸载本应用；
- **卸载本应用后，本机所有数据将被永久删除且不可恢复**，开发者亦无法协助恢复，请您谨慎操作。

### 5.3 数据安全

- 本机数据受 iOS 系统级加密保护（设备锁屏密码 / 生物识别）；
- 您可在 iOS 系统设置中开启"擦除数据"（10 次错误密码尝试后自动擦除）等安全选项进一步保护本机数据；
- 由于数据不上传，**不存在因开发者服务器被攻破而导致数据泄露的风险**。

## 6. 第三方共享与披露

我们承诺：

- **不与任何第三方共享您的健康数据**；
- **不向任何第三方出售您的个人信息**；
- **不与任何第三方建立数据合作或联合画像关系**；
- 在法律法规要求或政府机关依法强制要求时，可能依其要求提供必要信息（仅限法律法规明确许可的范围）。

## 7. 第三方 SDK

本应用**不集成任何广告 SDK、统计分析 SDK、推送 SDK 或跨应用追踪 SDK**。本应用使用的所有框架均为 Apple 官方提供（HealthKit、StoreKit、Vision、SwiftData、UIKit/SwiftUI 等），均在本机运行，不向任何第三方服务器发送您的数据。

## 8. 跨境数据传输

本应用**不向境外（含港澳台地区）传输您的任何个人信息**。所有数据处理均在您的本机完成，开发者不持有您的数据。

## 9. 未成年人保护

9.1 本应用面向**12 周岁及以上**用户。我们不会明知地收集未满 14 周岁儿童的个人信息。

9.2 如您是未满 14 周岁的儿童，请在监护人陪同下阅读本政策并使用本应用；如发现本应用涉及未成年人不当使用情形，请通过联系邮箱告知我们。

## 10. 您的权利

依据《个人信息保护法》及相关法律法规，您就本应用中您的信息享有以下权利：

| 权利 | 实现方式 |
|---|---|
| 知情权与决定权 | 阅读本政策；不下载、卸载本应用 |
| 查询、复制权 | 在本应用"记录""家庭档案"页面查看全部数据；如需导出请通过反馈邮箱联系 |
| 更正、补充权 | 在记录详情页编辑数值、在家庭档案页修改成员信息 |
| 删除权 | 在记录详情删除单条；在家庭档案删除成员；卸载应用清除全部本机数据 |
| 撤回同意权 | 在 iOS"设置 → 隐私 → 健康 / 相机 / 相册"中撤回对应权限 |
| 投诉举报权 | 通过联系邮箱向我们反馈，或向网信部门投诉举报 |

由于本应用数据全部本机存储，上述权利均可由您直接在本应用或 iOS 系统设置中完成，无需向我们提出申请。

11.1 本政策可能不时修订。修订后的政策将在本政策托管页面与应用内"设置 → 隐私政策"同步公布，并更新文首"生效日期"。

11.2 对于涉及数据使用方式、跨境传输、第三方共享等重大变更，我们将在应用内以显著方式告知。继续使用即视为接受修订后的政策；若不同意，请停止使用并卸载本应用。
