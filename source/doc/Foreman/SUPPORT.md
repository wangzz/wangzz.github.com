## 中文版

### 联系我们

如在使用 Foreman 时遇到问题、发现缺陷或有功能建议，请发送邮件至：

- wzzvictory_tjsd@163.com

请在邮件中附上：iPhone 型号与 iOS 版本、Foreman 版本号、Mac 型号与 macOS 版本、所用 Agent 名称，以及问题出现前后的操作步骤。涉及连接或构建问题时，可附上 Mac 端日志 `~/Library/Logs/Foreman/bridge.log` 的末尾片段（日志不包含会话正文）。

我们通常会在 1 个工作日内回复。

### 常见问题

完整的 Mac 安装与使用指南见：https://foogry.wang/doc/Foreman/guide.html

- 找不到菜单栏图标：Foreman 是纯菜单栏 App，用 Spotlight 搜索 Foreman 重新打开。
- 配对失败：配对码 5 分钟过期，请在 Mac 主窗口重新生成；确认手机与 Mac 均可联网。
- 模拟器画面黑屏或卡顿：在 macOS「系统设置 → 隐私与安全性 → 屏幕录制」中允许 Foreman，然后重新打开。
- 手机点按模拟器无反应：在「系统设置 → 隐私与安全性 → 辅助功能」中勾选 Foreman。
- 卸载与解绑：退出菜单栏 Foreman，删除「应用程序」中的 Foreman；手机端需重新配对。

## English Version

Please include: iPhone model and iOS version, Foreman version, Mac model and macOS version, the agent you use, and the steps that led to the issue. ### FAQ

The full Mac installation and usage guide is available at: https://foogry.wang/doc/Foreman/guide.html

- Menu bar icon missing: Foreman is a menu bar-only app. Search for Foreman in Spotlight to reopen it.
- Pairing fails: pairing codes expire after 5 minutes. Generate a new one in the Mac main window and make sure both devices are online.
- Simulator preview is black or slow: allow Foreman in macOS System Settings → Privacy & Security → Screen Recording, then reopen the app.
- Taps on the simulator do nothing: enable Foreman in System Settings → Privacy & Security → Accessibility.
- Uninstall and unpair: quit Foreman from the menu bar and delete it from Applications; the iPhone must pair again.
